# Glimreef support

Report a problem or ask a question about Glimreef, a game for iPhone and iPad, by
[opening an issue](https://github.com/glimreef/support/issues/new/choose).

**Issues are public.** Do not write your name, email address or other personal
information in them, and look over screenshots before you add them.

In the game, **Settings > About > report a problem** opens the form with the
version of the app and of your system already filled in. Write in whichever
language suits you.

The help page and privacy policy are at <https://glimreef.github.io/support/>.

The files here are published automatically from the game's own project. A change
made directly in this repository is replaced at the next publish.
